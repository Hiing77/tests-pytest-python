# 🧪 Autoformation QA Automation - Python & Pytest

Bienvenue sur mon projet d'apprentissage de l'automatisation de tests logiciels avec Python !

## 📌 Objectifs
Ce dépôt regroupe mes exercices et scripts de test réalisés dans le cadre de mon autoformation pour devenir **Testeur Logiciel / QA Automation**.

## 🛠️ Technologies utilisées
* **Langage :** Python 3
* **Framework de Test :** Pytest
* **IDE :** Visual Studio Code

## 🧠 Notions maîtrisées dans ce projet
- [x] **Bases Python :** Variables, boucles, fonctions et conditions.
- [x] **Structures de données :** Listes, dictionnaires, typage.
- [x] **Tests unitaires :** Assertions avec `pytest`.
- [x] **Gestion des cas aux limites :** Capture d'exceptions avec `pytest.raises`.
- [x] **Optimisation du code de test :** Fixtures (`@pytest.fixture`) et tests paramétrés (`@pytest.mark.parametrize`).
